# 🚀 SQL Practice Series #03
### Azure Data Engineering Journey | SQL Operators, Aggregate Functions & Clauses

> Turning business requirements into SQL solutions through hands-on practice with Azure SQL Database and SQL Server Management Studio (SSMS).

---

## 📌 Project Overview

This repository contains my first SQL practice project as part of my **Azure Data Engineering Journey**.

The objective was to strengthen my SQL fundamentals by solving real-world business scenarios using an E-Commerce dataset hosted on **Azure SQL Database**.

Every query in this repository was written, executed, and validated using **SQL Server Management Studio (SSMS)** connected to Azure SQL Database.

## 💡 Business Scenarios Practiced

Examples include:

- Finding customers using multiple filtering conditions
- Filtering records using ranges and pattern matching
- Calculating total revenue and average sales
- Identifying unique categories and cities
- Ranking cities based on revenue
- Grouping sales by category and sub-category
- Filtering aggregated results using HAVING
- Retrieving Top N performing records
