# SQL Practice Series – 02 | String Functions

This repository contains my hands-on SQL practice focused on **String Functions** using **Microsoft SQL Server Management Studio (SSMS)** connected to **Azure SQL Database**.

The exercises were performed using the **Superstore dataset** to understand how string functions are used in real-world data cleaning and transformation scenarios. :contentReference[oaicite:2]{index=2}
